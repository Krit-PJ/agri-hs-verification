# รุ่น 1.6 ตรวจและปรับการใช้บน Smartphone
พบ: CSS เดิมซ่อนบรรทัดรองของหัวเว็บไซต์บนมือถือ, เมนูต้องเปิดก่อน, รายการยาวขวางตัวกรอง, ภาพหลักฐานถูกจำกัดสัดส่วนจนข้อมูลสอบทวนอาจถูกตัด, แบบบันทึกมีพื้นที่เลื่อนซ้อนและปุ่มล่างอาจบังเนื้อหา
แก้ไข: แสดงหัวครบสามบรรทัด เมนูหลักแบบสองคอลัมน์กดได้ทันที ฟอร์มและผู้ดูแลหนึ่งคอลัมน์ ช่องกรอก 16px ปุ่มอย่างน้อย 48px ยกเว้นปุ่มของแผนที่ที่ใช้ไลบรารีเดิม แผนที่ปรับตามความสูงหน้าจอ รายการมีพื้นที่เลื่อนจำกัด ตารางเลื่อนแนวนอนภายในกรอบพร้อมชื่อให้โปรแกรมอ่านหน้าจอ แบบบันทึกสูงตาม viewport ปุ่มปิดติดส่วนหัว ปุ่มบันทึกอยู่ท้ายฟอร์มไม่บังเนื้อหา แสดงรายละเอียดภาพครบ พร้อม safe-area และแนวนอน
ไม่มีการเปลี่ยนสิทธิ์ Admin/Super Admin หรือฐานข้อมูล ไม่บันทึกข้อมูลทดสอบลงส่วนกลาง
ข้อจำกัด: การจำลอง viewport ไม่ใช่อุปกรณ์จริง ยังต้องทดสอบคีย์บอร์ด กล้อง GPS การพิมพ์ PDF และการเชื่อม Apps Script จริงบน Safari/iOS และ Chrome/Android ก่อนเปิดใช้งานภาคสนาม ไม่รับรองทุกเครื่อง/ทุกเบราว์เซอร์
