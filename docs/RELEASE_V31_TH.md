# v3.1 — ลงทะเบียน Admin ใช้งานได้ทันที, ขั้นตอนบันทึกผลภาคสนาม, ปรับการแสดงผลบนมือถือ

## บัญชีผู้ใช้
* **Admin ลงทะเบียนเองแล้วใช้งานได้ทันที** ด้วยเบอร์โทรศัพท์ (ไม่มีรหัสผ่าน/PIN) ระบบเข้าสู่ระบบให้อัตโนมัติหลังลงทะเบียน
* **Mini Super Admin แต่งตั้งได้โดย Super Admin เท่านั้น** — ตัดตัวเลือกขอเป็น Mini Super Admin ออกจากฟอร์ม และเซิร์ฟเวอร์บันทึกผู้ลงทะเบียนเป็น Admin เสมอ
* แท็บ **ผู้ลงทะเบียน** ของ Mini Super Admin / Super Admin แสดงผู้ลงทะเบียนพร้อมสถานะบัญชีและปุ่มระงับ/เปิดใช้ (มีผลทันที) · เบอร์ที่ถูกระงับลงทะเบียนซ้ำไม่ได้
* จำกัดการลงทะเบียน 30 ครั้งต่อ 10 นาที กันการสมัครรัว ๆ
* เข้าสู่ระบบค้างไว้ได้ 8 ชั่วโมงแม้ปิดแท็บ (เหมาะกับมือถือภาคสนาม)

## งานภาคสนาม (Admin)
* **แถบงานภาคสนาม** ใต้ส่วนเลือกจังหวัด: ผู้ใช้ทั่วไปเห็นปุ่ม “ลงทะเบียน Admin / เข้าสู่ระบบ” · เจ้าหน้าที่เห็นจำนวนรอตรวจ/ร่าง/ตรวจแล้ว และปุ่ม **⌖ จุดรอตรวจใกล้ฉัน** (เรียงตามระยะ) กับ **รายการรอตรวจ**
* ทุกการ์ดจุดมีปุ่ม **บันทึกผล ›** ชัดเจน และปุ่ม “แผนที่” เพื่อซูมไปยังจุด
* แตะจุดโดยยังไม่เข้าสู่ระบบ → มีปุ่มเข้าสู่ระบบ/ลงทะเบียนในหน้าจุดนั้น เสร็จแล้ว **ระบบเปิดฟอร์มของจุดเดิมให้อัตโนมัติ**
* ฟอร์มบันทึกผลจัดเป็น 4 ขั้น: 1 ตำแหน่ง → 2 ผลการตรวจ → 3 ภาพถ่าย → 4 รายละเอียดเพิ่มเติม · ปุ่มส่งอยู่ด้านล่างจอตลอด · ระบบหาตำแหน่งให้อัตโนมัติเมื่อเคยอนุญาตตำแหน่งแล้ว · แจ้งขั้นที่ยังไม่ครบและเลื่อนไปยังจุดนั้น · จำประเภทผู้ลงพื้นที่ไว้ใช้ครั้งถัดไป
* หน้า “งานของฉัน” แสดงผลตรวจที่ตนบันทึกและบันทึกการใช้งานของตนเอง

## การแสดงผล
* มือถือ: ส่วนหัวกระชับ เมนู ☰ · ตัวกรองพับได้และแสดงตัวกรองที่เลือกเป็นป้าย · แผนที่ขึ้นภายในจอแรก (เดิมต้องเลื่อนเกือบ 2 จอ) · แถบจำนวนจุด/สลับแผนที่-รายการติดด้านบน · ปุ่ม “↑ แผนที่” เมื่อเลื่อนรายการยาว
* ตัวเลือกขอบเขตอำเภอ/ตำบล ปุ่มดูเต็มจังหวัด และตำแหน่งฉัน ย้ายเข้าไปอยู่บนแผนที่
* เดือน–ปีจัดกลุ่มตามปีงบประมาณ · ตารางในหน้าผู้ดูแลแสดงเป็นการ์ดรายแถวบนจอแคบ · ฟอร์มเพิ่มบัญชีพับเก็บได้
* ตัวนับ: ผู้เข้าชมวันนี้ / ทั้งหมด / เจ้าหน้าที่ใช้งานวันนี้ และแสดงข้อความแทนพื้นที่ว่างเมื่อยังไม่เชื่อมฐานข้อมูล

## ฐานข้อมูล
* ชีต `Requests` เพิ่มคอลัมน์ `accountId` (เพิ่มในฐานข้อมูลจริงแล้ว) · `status` ของการลงทะเบียนใหม่ = `auto_approved`
