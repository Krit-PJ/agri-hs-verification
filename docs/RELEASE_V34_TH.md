# รุ่น 3.4 — รายงานพร้อมภาพหลักฐาน

ต้องอัปเดต Apps Script (มีคำสั่งใหม่ `report_photos`) — ระบบตอบ `ping` เป็น 3.4.0

## สิ่งที่เพิ่ม/แก้

1. **พิมพ์รายงาน / PDF แนบภาพหลักฐาน** — เมื่อเจ้าหน้าที่เข้าสู่ระบบ หน้า “สรุปผลการตรวจสอบ” มีตัวเลือก **แนบภาพหลักฐาน** (บอกจำนวนจุดที่มีภาพ)
   * รายงานเพิ่มหัวข้อ **ภาพหลักฐานการตรวจสอบรายจุด** เริ่มหน้าใหม่ จุดละ 1 กรอบ: พื้นที่ ผลตรวจ วันที่ HS พืช วันเวลาตรวจ ผู้ตรวจ GPS ระยะจากจุด HS หมายเหตุ และภาพสูงสุด 3 ภาพพร้อมเวลาถ่าย
   * เฉพาะผล “ตรวจแล้ว” ที่มีภาพ ในขอบเขตตัวกรองปัจจุบันและขอบเขตสิทธิ์ของผู้ใช้ (Admin/Mini Super Admin = จังหวัดของตน, Super Admin/ระดับประเทศ = ทุกจังหวัด)
   * ดึงภาพครั้งละ 10 จุด แสดงความคืบหน้า ย่อภาพเหลือด้านยาว 1,000 px ก่อนใส่รายงาน แนบได้สูงสุด 150 จุดต่อรายงาน (เกินนั้นให้กรองพื้นที่ให้แคบลง)
   * ผู้ใช้ทั่วไปพิมพ์รายงานได้เหมือนเดิมแต่ไม่มีภาพ (ภาพเป็นข้อมูลส่วนตัว) · การพิมพ์รายงานพร้อมภาพบันทึกใน AuditLog (“พิมพ์รายงาน”)
   * ตารางจุดพบการเผาเพิ่มคอลัมน์จำนวนภาพ (และจังหวัดเมื่อดูทุกจังหวัด) · ท้ายรายงานระบุผู้พิมพ์
   * หน้ารายงานมีแถบ **‹ ปิดรายงาน** และ **พิมพ์ / บันทึก PDF** (ไม่แสดงเมื่อพิมพ์) และเปิดหน้าพิมพ์อัตโนมัติเมื่อภาพโหลดครบ
2. **ปุ่ม ‹ กลับหน้าหลัก** ในหน้าสรุปผลการตรวจสอบ และหน้าผู้ดูแลระบบ
3. ตรวจส่วนอื่น ๆ แล้วปรับเพิ่ม
   * แท็บ “ผลการตรวจสอบ” ของผู้ดูแลมีปุ่ม **ดู / แก้ไข** เปิดฟอร์มผลตรวจของจุดนั้นได้ทันที (เดิมต้องไปหาจุดบนแผนที่)
   * ฟอร์มผลตรวจ **โหลดภาพที่บันทึกไว้ให้อัตโนมัติ** (เดิมต้องแตะทีละภาพ) ถ้าโหลดไม่สำเร็จแตะเพื่อลองใหม่ได้
   * แก้ปัญหาหน้ารายงานบางเบราว์เซอร์ไม่เปิดหน้าพิมพ์อัตโนมัติ
