# HS Verification v2.9 — Registration reliability

แก้ไขตามคำขอ 21 ตุลาคม 2569 โดยคงโครงสร้าง UI รุ่น 2.8.1 และบัญชีเดิม

## การปรับปรุง
- ยกเลิกการพึ่ง native submit validation ที่อาจบล็อก event โดยไม่แสดงข้อความในขั้นตอนที่ซ่อนอยู่ ใช้การตรวจฟอร์มอย่างชัดเจนในแต่ละขั้นแทน ช่องจำเป็นและการรับทราบประกาศยังบังคับครบ
- ปุ่มยืนยันไม่เงียบเมื่อยังไม่ได้รับทราบ: แสดงข้อความและพาไปยังช่องรับทราบ ห้ามส่งคำขอจนกว่าจะรับทราบแล้ว
- แสดงกำลังส่งคำขอและกันกดซ้ำ; โหลดประกาศจำกัด 30 วินาที ส่งคำขอจำกัด 90 วินาที หากเกินกำหนดแจ้งว่าสถานะอาจบันทึกแล้วและให้ตรวจสอบก่อนส่งซ้ำ ไม่มีการส่งคำขอซ้ำอัตโนมัติ
- ข้อความสำเร็จแสดงเฉพาะเมื่อ API ส่งสถานะ pending พร้อม registrationId: “ลงทะเบียนสำเร็จ รอการอนุมัติจากผู้ดูแลระบบ” ผู้ดูแลจังหวัดระบุ Super Admin เพิ่มเติม
- ผู้บันทึกยังจำเบอร์ล่าสุดและเปิดหน้าเข้าสู่ระบบหลังส่งคำขอ แต่ต้องได้รับอนุมัติก่อนใช้งานจริง ผู้ดูแลจังหวัดยังใช้ชื่อผู้ใช้และรหัสผ่านเดิมตามรูปแบบบัญชี
- Super Admin ตรวจรายการและอนุมัติ/ปฏิเสธผู้บันทึกทุกจังหวัด และคำขอ Admin รายจังหวัดได้ Admin จังหวัดอนุมัติผู้บันทึกเฉพาะพื้นที่ของตน ไม่มีการสมัคร Super Admin สาธารณะ
- ป้องกันผลรายการคำขอเก่ากลับมาแสดงเมื่อเปลี่ยนบัญชี โดยยังให้ปุ่มอนุมัติทำงานหลังสลับหน้าในบัญชีเดิม
- Apps Script บันทึกรหัสข้อผิดพลาดโดยไม่บันทึก payload หรือข้อมูลส่วนบุคคล; เพิ่ม diagnoseRegistrationReadinessV29 แบบอ่านอย่างเดียว

## หลักฐานตรวจสอบ
- ชีต User_Registration/Admin_Registration จริงมีหัวคอลัมน์ตรง schema และตั้งค่าประกาศครบ พื้นที่บัญชียังไม่เต็ม
- Node test 242 ผ่าน: รวม register API ผ่าน Repository จริงกับ Sheets จำลอง, เบอร์โทรเป็นข้อความ, pending ก่อนอนุมัติ, login หลังอนุมัติ, ขอบเขตจังหวัด, Super review, CSRF, rollback, double click, timeout, stale response และ UI เดิม
- ทดสอบ native Browser form ทั้งผู้บันทึกและ Admin ด้วยระบบจำลองที่ไม่สร้างบัญชีจริง ยืนยันข้อความแจ้งรับทราบ/รออนุมัติ
- Apps Script source รวม: docs/AppsScript-v29-All.gs; ก่อนเผยแพร่รัน diagnoseRegistrationReadinessV29 ต้อง policyReady=true และ headersMatch=true ทั้งสองชีต ไม่มีการเปลี่ยน schema หรือรหัสผ่าน

## วิธีใช้
ผู้สมัคร: เข้าใช้งานระบบ → ลงทะเบียนใหม่ → กรอกข้อมูล → อ่านประกาศ/รับทราบ → ยืนยัน → รอการอนุมัติจากผู้ดูแลระบบ
ผู้ดูแลจังหวัด: เมนูเพิ่มเติม → ผู้ดูแลระบบ → ลงทะเบียนใหม่ → ส่งคำขอ → รอ Super Admin
Super Admin: เมนูเพิ่มเติม → ผู้ดูแลระบบ → เข้าสู่ระบบ → โหลดคำขอผู้บันทึก หรือคำขอผู้ดูแลรายจังหวัด → ตรวจข้อมูลและอนุมัติ/ไม่อนุมัติ
ไม่อนุมัติคำขอจริงหรือสร้างบัญชีจริงเพื่อการทดสอบระหว่างติดตั้ง

ติดตั้ง Google Apps Script รุ่น 2.9.0 สำเร็จ: deployment version11 วันที่ 21 ตุลาคม 2569 ใช้ endpoint เดิม ตรวจ readiness บน Google ผ่านและสำรอง source ก่อนอัปเดตแล้ว
