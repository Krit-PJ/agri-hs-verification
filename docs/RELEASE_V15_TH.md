# รุ่น 1.5
- ปรับลำดับขนาดหัวเว็บไซต์และเมนูตามคำขอ
- ปุ่มจุดความร้อนทั้งหมดล้างทุกตัวกรอง รวมถึงปี และปรับแผนที่/รายการพร้อมกัน สถานะ Active คำนวณจากตัวกรองจริง
- เปลี่ยนข้อความหัวงานและเหตุผลที่ไม่แนบภาพ โดยไม่เพิ่มภาระการกรอก
- กล้องใช้ native file input ที่รับการแตะโดยตรง accept=image/* capture=environment และถ่ายทีละรูป รวมได้ 3 รูป ส่วนการนำเข้ารูปยังเลือกได้หลายรูป
- รูปแบบที่ประมวลผลรองรับ JPEG/PNG/WebP หากเครื่องส่ง HEIC ที่เบราว์เซอร์อ่านไม่ได้ ให้เลือก JPEG หรือแปลงก่อน
- capture ขึ้นกับระบบปฏิบัติการ/เบราว์เซอร์ ไม่รับประกันทุกเครื่อง เปิดใน Safari/Chrome โดยตรงเมื่อเบราว์เซอร์ในแอปไม่รองรับ หรือถ่ายด้วยแอปกล้องแล้วนำเข้ารูปภาพ
- ไม่สร้าง/เปลี่ยนพิกัด EXIF ที่ไม่มีในต้นฉบับ และยังใช้วิธีตรวจสอบหลักฐานเดิม
- ไม่เปลี่ยน Apps Script หรือโครงสร้างข้อมูลในรุ่นนี้
- ยังไม่ได้ทดสอบกล้องจริงบนอุปกรณ์ iOS/Android
อ้างอิง: https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/capture
