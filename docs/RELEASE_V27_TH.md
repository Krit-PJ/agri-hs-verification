# HS Verification v2.7

รุ่นนี้รวมทางเข้าสำหรับผู้บันทึกข้อมูล, Admin จังหวัด และ Super Admin ในหน้าต่าง “เข้าใช้งานระบบ” มี “ลงทะเบียนใหม่” ด้านล่าง

## ใช้งาน
- ผู้บันทึก: เข้าใช้งานระบบ → ผู้บันทึกผลตรวจ → โทรศัพท์ที่ได้รับอนุมัติแล้ว
- ผู้ดูแลเดิม: เข้าใช้งานระบบ → ผู้ดูแลระบบ → ชื่อผู้ใช้และรหัสผ่านเดิม
- ผู้ดูแลจังหวัดใหม่: ลงทะเบียนใหม่ → ผู้ดูแลระบบรายจังหวัด → กรอกโทรศัพท์ ชื่อ ตำแหน่ง กลุ่มงาน เลือกสำนักงานเกษตรจังหวัด (จังหวัดเติมอัตโนมัติ) ตั้งชื่อผู้ใช้/รหัสผ่านของตนเอง → อ่านประกาศ PDPA เดิมและรับทราบ → ส่งคำขอ
- Super Admin: ผู้ดูแลระบบ → “อนุมัติผู้ดูแลระบบรายจังหวัด” → โหลดคำขอ → ตรวจตัวตนและสังกัด → อนุมัติ/ไม่อนุมัติ
- ผู้สมัครยังไม่มีสิทธิ์ก่อนอนุมัติ Admin จังหวัดไม่มีสิทธิ์อนุมัติ Admin คนอื่น บัญชีและรหัสผ่านเดิมไม่เปลี่ยน

## Apps Script
ใช้ `docs/AppsScript-v27-All.gs` เป็นโค้ดรวมแทนไฟล์เดิม (สำรองก่อน) แล้วบันทึก เรียก `setupRuntimeV27` หนึ่งครั้ง สร้างเฉพาะชีต `Admin_Registration` ตรวจ version2.7.0, privacyConfigured=true, adminRequestsSheetReady=true แล้วปรับ deployment เดิมเป็นเวอร์ชันใหม่โดยคง URL
ไม่มีการสร้างบัญชีจริงหรืออนุมัติบุคคลจากฟังก์ชันติดตั้ง รหัสผ่านผู้สมัครเก็บ hash ใน Script Properties เท่านั้น ไม่เก็บใน Sheet/log/เบราว์เซอร์

## ลดเวลารอ
- ตรวจ schema เฉพาะชีตลงทะเบียน แทนการจัดรูปแบบทุกชีตซ้ำ
- เปิด Spreadsheet และอ่านแต่ละตารางครั้งเดียวต่อคำขอ โดยยกเลิกสำเนาหลังเขียน และล้างทุกคำขอ ไม่ใช้ข้ามบัญชี
- หลังยืนยันตัวตนแล้วปิดหน้าต่างล็อกอินทันที แยกการโหลดข้อมูลแผนที่ต่อเบื้องหลัง พร้อมล้างข้อมูลจากสิทธิ์เดิมก่อนโหลด
- คงการตรวจสิทธิ์ อนุมัติ และความเข้มของรหัสผ่านเดิม ความเร็วจริงยังขึ้นกับเครือข่ายและการเริ่มทำงานของ Google Apps Script ไม่รับประกันเวลาคงที่

## ตรวจสอบ
Node test suite และ syntax ของ JS/Apps Script รวม; ทดสอบบทบาท pending/approved, Super-only approval, CSRF, duplicate phone/username, PDPA, tamper, รูปแบบโทรศัพท์ และการล็อกอินไม่รอแผนที่
