# รุ่น 3.7 — สำเนาจุดความร้อนพร้อมเว็บ (เร็วขึ้น) + ปุ่มอัปเดตข้อมูล

ไม่ต้องอัปเดต Apps Script

## วิธีทำงาน
1. **GitHub Actions** ดึงจุดความร้อนจาก API ระบบ Agri-Risk Map (`fn=hotspots`) ทุกจังหวัด × 6 ประเภทพื้นที่ เก็บเป็นไฟล์ `data/hs/<จังหวัด>/<ประเภท>.json` + `data/hs/index.json` แล้วเผยแพร่พร้อมเว็บ (ไม่บันทึกลง Git → repo ไม่โต)
   * ตามเวลา: **ทุกวัน 09:00 และ 12:00 น.** (cron `0 2,5 * * *` UTC — GitHub อาจเริ่มช้ากว่ากำหนดได้บ้างในช่วงที่มีงานมาก) และทุกครั้งที่อัปเดตเว็บ
   * จังหวัดที่ต้นทางไม่เปลี่ยน (`updatedAt` เท่าเดิม) ใช้ไฟล์ชุดเดิม ไม่เรียก API ซ้ำ
   * ขอไม่สำเร็จ: ลองใหม่ 3 ครั้ง → ใช้ไฟล์ชุดเดิม → ถ้าไม่มี หน้าเว็บอ่าน API สดแทน (การเผยแพร่เว็บไม่หยุด)
   * สั่งอัปเดตทันทีได้ที่ GitHub → Actions → Publish static site → Run workflow
2. **หน้าเว็บ** อ่านไฟล์สำเนาก่อน แล้วกรองช่วงเดือนในเครื่อง — เปลี่ยนประเภทพื้นที่/ช่วงเดือนได้ทันทีโดยไม่เรียก API
3. **ปุ่ม "อัปเดตข้อมูล"** (แถบเครื่องมือ — บนมือถือเป็นปุ่ม ↻) อ่านล่าสุดจาก API สำหรับประเภทพื้นที่ที่เลือก แล้ว**จำไว้ในเบราว์เซอร์** (IndexedDB) ครั้งต่อไปใช้ชุดที่ใหม่กว่าระหว่างสำเนากับที่จำไว้
4. แถบผลลัพธ์แสดง **"ข้อมูล ณ วัน เวลา"** ของชุดที่แสดงอยู่
5. สถานะ/ผลตรวจยังอ่านสดจากฐานข้อมูลของระบบนี้ทุกครั้ง

ข้อมูลในไฟล์สำเนาเป็นข้อมูลสาธารณะชุดเดียวกับที่ API ระบบ Agri-Risk Map เปิดอยู่ (ไม่มีผลตรวจ ชื่อผู้ใช้ หรือภาพ)
