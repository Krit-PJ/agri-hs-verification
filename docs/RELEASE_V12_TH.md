# การปรับปรุง v1.2 และผลตรวจรับ

## สิ่งที่ใช้งานได้
- ประเภทบุคคล: นักวิชาการส่งเสริมการเกษตร, กำนัน, ผู้ใหญ่บ้าน, ผู้ช่วยผู้ใหญ่บ้าน, อกม., อื่นๆ (ต้องระบุ) แยกจากสิทธิ์ inspector/admin/super_admin
- คลิก HS แล้วระบบเติมข้อมูลต้นทางและตัวกรองให้ ผู้ใช้เลือกผลตรวจ แนบภาพหรือเลือกเหตุผลเมื่อไม่มีภาพ ประเภทบุคคลจำจากโปรไฟล์หรืออุปกรณ์
- ช่องตรวจย้อนหลังและบันทึกแทนซ่อนในรายละเอียด ผู้ส่งรายงานตรวจสอบจากบัญชีฝั่งเซิร์ฟเวอร์เสมอ
- สภาพพื้นที่จริง/ชนิดพืชที่พบแยกจาก HS เดิม ไม่เขียนทับต้นทาง
- JPEG ต้นฉบับอ่านพิกัด/เวลาจาก EXIF และระยะถึง HS อัตโนมัติ เซิร์ฟเวอร์อ่านซ้ำจากไบต์ต้นฉบับ เก็บ hash และผลสอบทวน
- พิกัดภาพเป็นจุดสีน้ำเงินและเส้นเชื่อมบนแผนที่ แยกจาก HS ไม่ถือว่าเป็นตำแหน่งของวัตถุที่ถ่าย
- ไม่มี GPS อุปกรณ์แต่มีพิกัด EXIF ใช้ส่งสอบทวนได้ โดยระบบบันทึกเหตุผลและแหล่งพิกัดแยกกัน
- สรุปทั้งจังหวัดแยกงานติดตามและงานรอหลักฐานออกจากผลที่ยืนยันแล้ว
- Design System พร้อม typography H1–H6, สี HEX, semantic tokens, ปุ่ม ตาราง การ์ด ฟอร์ม ไอคอน และแนวทาง accessibility ใน DESIGN_SYSTEM_TH.md

## การทดสอบ
69 กรณีผ่าน: backend, data import/source, EXIF, frontend fields, security role และ contrast tokens พร้อมตรวจ syntax JavaScript/Apps Script
ทดสอบผ่านหน้าเว็บจริง: HS593จุด เปิดฟอร์ม เติมอำเภอ เลือกอื่นๆ เปิดช่องระบุ เลือกผลและเหตุผลไม่มีGPS/ภาพ เปิดหน้ายืนยันและยกเลิกโดยไม่ส่งข้อมูล ทดสอบจอ390pxไม่มีแนวนอนล้นและdialogไม่ล้น

## ข้อจำกัดที่ต้องทราบ
- ยังไม่ deploy จริง ต้องเชื่อม Google และตรวจ Apps Script/Drive permissions ด้วยบัญชีจริง
- ภาพ JPEG เท่านั้นที่อ่าน EXIF; PNG/WebP แนบต้นฉบับได้แต่ไม่อ่าน metadata; HEIC ไม่รองรับ ภาพละ5MB สูงสุด3ภาพ
- ปุ่มกล้องใช้ตัวเลือกกล้องของระบบปฏิบัติการ ไฟล์ที่ได้ยังต้องตรวจ EXIF จึงไม่อ้างว่าได้ GPS ณ เวลาถ่ายจาก session กล้อง
- ไม่มีเกณฑ์รัศมีความคลาดเคลื่อนจากผลิตภัณฑ์ HS ต้นทาง จึงไม่รับรองพิกัดอัตโนมัติ และยังไม่มีหน้าตั้งเกณฑ์เชิงตำแหน่ง
- EXIF เปลี่ยนแปลงได้ SHA-256 ใช้สอบทวนไฟล์ที่เก็บและตรวจซ้ำ ไม่ยืนยันสถานที่ถ่ายจริง
- โหมดทดลองเก็บผลบนอุปกรณ์ แต่ไม่เก็บภาพขึ้น Drive; โหมดเชื่อมต่อจริงมีคิวส่งซ้ำเมื่อส่งไม่สำเร็จ
- ตรวจ contrast tokens แล้ว แต่ยังไม่ใช่การรับรอง WCAG AA ทั้งเว็บไซต์ ต้องทดสอบ screen reader และอุปกรณ์ภาคสนามเพิ่ม
