# HS Verification v2.8.1

ปรับเฉพาะ Frontend ตามคำขอ 2026-10-20 โดยคงสิทธิ์และการทำงาน API รุ่น 2.8.0 (Apps Script deployment10)

- ไม่แสดงการ์ดขอบเขตการปกครอง แต่คงโหลด/เน้นแนวเขตอัตโนมัติตามจังหวัด ตัวกรอง และพิกัด HS
- จังหวัดในตัวกรองจุดความร้อนเชื่อมกับจังหวัดหลักและล็อกไม่ให้แก้ ส่วนตัวกรองอื่นทำงานเดิม
- เมนูหลักแสดง เข้าใช้งานระบบ เมื่อยังไม่เข้าสู่ระบบ และ ออกจากระบบ เมื่อยืนยัน session แล้ว ใช้กระบวนการ logout เดิมทั้งผู้บันทึก Admin และ Super Admin
- ซ่อนแถบชื่อบัญชี/ออกจากระบบที่ซ้ำกับ Hero และเมนู รวมถึงพื้นที่ว่างเดิมเหนือเมนู
- ตารางสรุประดับอำเภอ ตำบล หมู่บ้าน ตัดชื่อจังหวัดที่นำหน้าออก แต่ยังจัดกลุ่มแยกรหัสพื้นที่/จังหวัดเดิม ไม่รวมยอดข้ามจังหวัด ระดับทั้งจังหวัดยังแสดงชื่อจังหวัดเป็นชื่อพื้นที่

ตรวจสอบ: Node tests 232 ผ่านทั้งหมด; syntax JavaScript ผ่าน; reviewer ไม่พบ regression; บัญชีจำลองใน browser ออกจากระบบได้จริงและกลับเป็นปุ่มเข้าใช้งานระบบ การ์ดขอบเขตและแถบบัญชีซ้ำไม่แสดง จังหวัดในตัวกรองถูกล็อก

ไม่เปลี่ยนบัญชี รหัสผ่าน PDPA การอนุมัติ หรือ Apps Script รุ่นที่เผยแพร่ ข้อจำกัดชุดขอบเขตเดิมยังใช้ตาม docs/RELEASE_V28_TH.md
