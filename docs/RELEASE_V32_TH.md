# v3.2 — ดูข้อมูล HS ทุกจังหวัด, Mini Super Admin ระดับประเทศ, ประวัติการเข้าใช้งาน

## 1. ดูข้อมูล HS ทุกพื้นที่บนแผนที่ (Super Admin / Mini Super Admin ระดับประเทศ)
* ช่องเลือกจังหวัดมีตัวเลือก **★ ทุกจังหวัดที่มีข้อมูล** แสดงจุด HS ทุกจังหวัดบนแผนที่พร้อมกัน (อ่านพร้อมกันครั้งละ 4 จังหวัด แสดงความคืบหน้า)
* ตัวกรองเพิ่มช่อง **จังหวัด** เพื่อเจาะดูทีละจังหวัด (แสดงขอบเขตจังหวัด/อำเภอ/ตำบลบนแผนที่) · การ์ดจุดแสดงชื่อจังหวัด
* สรุปผลมีระดับ **จังหวัด** สรุปความคืบหน้าทุกจังหวัด · รายงานพิมพ์และ CSV ใช้หัวข้อ “ทุกจังหวัด”
* ผู้ใช้ทั่วไป / Admin / Mini Super Admin ระดับจังหวัด ไม่เห็นตัวเลือกนี้ และเซิร์ฟเวอร์ตรวจสิทธิ์ทุกคำสั่ง

## 2. Super Admin แต่งตั้ง Mini Super Admin
* แท็บ **บัญชีผู้ใช้** ของ Super Admin มีส่วน **แต่งตั้ง Mini Super Admin** 2 แบบ
  * **ระดับประเทศ (ทุกจังหวัด)** — จัดการระบบได้เหมือน Super Admin: ข้อมูล HS และผลตรวจทุกจังหวัด บัญชี Admin ทุกจังหวัด ผู้ลงทะเบียน บันทึกและประวัติการเข้าใช้งาน · **ยกเว้น** บัญชี Super Admin, บัญชี Mini Super Admin และการตั้งค่าระบบ
  * **ระดับจังหวัด** — เหมือนเดิม
* บัญชี **Super Admin แสดงเป็นแถวล็อก 🔒** ในรายการบัญชี ไม่มีบทบาทใดลบหรือระงับได้ (Super Admin ไม่อยู่ในชีต Accounts และ API ไม่มีคำสั่งลบ)
* รหัสบัญชี Mini Super Admin ระดับประเทศขึ้นต้น `A-TH-` · ชีต Accounts ใช้ `provinceCode = ALL`

## 3. ประวัติการเข้าใช้งานระบบ
* แท็บ **ประวัติการเข้าใช้งาน** (ทุกบทบาท): ตัวเลขสรุปวันนี้, กราฟรายวัน (เข้าสู่ระบบ / เปิดใช้งาน / ไม่สำเร็จ), สรุปรายบุคคล (จำนวนครั้ง ครั้งแรก ล่าสุด อุปกรณ์ล่าสุด), รายการทุกการเข้าสู่ระบบ, หมายเลขที่ไม่มีในระบบแต่พยายามเข้าใช้ (ระดับประเทศ) และส่งออก CSV
* ตัวกรอง: 7/30/90/365 วัน หรือช่วงวันที่, บทบาท, จังหวัด, ผล, คำค้น
* บันทึก **การเปิดใช้งาน** ของผู้ที่เข้าสู่ระบบค้างไว้ (ไม่เกิน 1 ครั้ง/30 นาที/คน) เพิ่มจากการเข้าสู่ระบบ/ออกจากระบบ
* ขอบเขตการเห็น: Super Admin ทั้งหมด · Mini Super Admin ระดับประเทศ ทั้งหมดยกเว้น Super Admin · Mini Super Admin ระดับจังหวัด เฉพาะจังหวัด · Admin เฉพาะตนเอง

## การทดสอบ
`npm test` 30 รายการผ่าน · ทดสอบในเบราว์เซอร์: Super Admin เลือกทุกจังหวัด → กรองจังหวัด → สรุประดับจังหวัด → แต่งตั้ง Mini Super Admin ระดับประเทศ → บัญชีนั้นเข้าสู่ระบบเห็นทุกจังหวัดแต่จัดการบัญชี Mini Super Admin ไม่ได้ → ประวัติการเข้าใช้งาน (เดสก์ท็อปและมือถือ ไม่ล้นจอ)
