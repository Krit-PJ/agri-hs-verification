# ผลส่งมอบ v1.3

## การเปลี่ยนแปลง
1. Typography หัวข้อ32–44px, มือถือ30px; H2 24–30px; เนื้อหา16px และข้อความกำกับ13px ฟอนต์ไทยบรรจุในชุดงาน
2. Login ฝั่ง Apps Script สำหรับ620000/Admin และKrit/Super Admin เก็บแฮชพร้อมsalt/pepper เซสชัน4ชั่วโมง ออกจากระบบเพิกถอนเซสชัน จำกัดการลองผิด5ครั้งต่อชื่อผู้ใช้ใน15นาที และล็อกการตรวจพร้อมกัน
3. หน้าผู้ดูแลซ่อนก่อนยืนยันบัญชีจากเซิร์ฟเวอร์ Adminไม่เห็นการตั้งค่าเซิร์ฟเวอร์/Workspace/นำเข้า Super Adminจัดการทั้งสามส่วนได้ รวมปุ่มซิงก์ต้นทางให้อยู่แห่งเดียว
4. รายงานตามอำเภอ/ทั้งจังหวัดและปีที่เลือก มีโลโก้ ยอดรวม งานร่าง ผลตรวจ ผู้ลงพื้นที่ วันเวลาตรวจ หมายเหตุ และข้อมูลHSต้นทาง เปิดในแท็บเดิมไม่พึ่งป๊อปอัป พิมพ์A4แนวนอนแล้วเลือกบันทึกเป็นPDF
5. โลโก้โปร่งใส DOAE/KPP อยู่ในassets ไฟล์ต้นทางของผู้ใช้ไม่ได้ถูกแก้ไข

## เปิดใช้งาน
เปิด Start-Preview.ps1 หรือ http://127.0.0.1:8081/?version=13
นำ Apps Script ทั้งหมดขึ้นโครงการ สำรองฐานและรัน migrateSchemaV12() ถ้ายังไม่ได้อัปเกรดจากฐานเดิม จากนั้นตั้งบัญชีตาม AUTH_SETUP_TH.md แล้วdeployเวอร์ชันใหม่

## ข้อจำกัด
ยังไม่ได้ตั้งค่าหรือdeployบัญชีGoogleจริง จึงยังไม่ได้ทดสอบLoginผ่านGoogleจริง บัญชีตามที่ขอต้องใส่รหัสผ่านในScript Propertiesก่อนใช้งาน ไม่มีรหัสผ่านฝังในFrontend
การพิมพ์PDFใช้ความสามารถเบราว์เซอร์ ผู้ใช้เลือกปลายทางSave as PDF หากเบราว์เซอร์ในแอปไม่รองรับให้เปิดChrome/Edge ยังไม่มีการสร้างPDFบนเซิร์ฟเวอร์หรือแนบไฟล์ภาพทุกใบในรายงาน
คงช่องทางtokenเดิมสำหรับย้ายระบบและเจ้าหน้าที่ แต่หน้าAdminใหม่ใช้Login; เซิร์ฟเวอร์ยังตรวจสิทธิ์ทุกคำขอ
งาน A1 กระจายหลายGoogleSheets ยังไม่รวมในรุ่นนี้
