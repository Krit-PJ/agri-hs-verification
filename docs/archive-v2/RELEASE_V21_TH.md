## ทดลองโดยไม่ต้อง Login
เปิด Start-Preview.ps1 แล้วเข้า http://127.0.0.1:8081/?version=21 หน้าเว็บเริ่มด้วย Super Admin ทดสอบ เลือก Admin รายจังหวัดหรือผู้ใช้ทั่วไปได้จากแถบสีเหลือง

ทำงานเฉพาะ localhost/127.0.0.1 เมื่อ site-config.js ตั้ง previewMode: true และ apiEndpoint ว่าง บันทึกข้อมูลในพื้นที่ทดสอบของเบราว์เซอร์ แยกจากข้อมูลเดิม ไม่ส่งคำสั่งจำลองไป Apps Script

ทดลองหน้าผู้ดูแล การนำเข้าไฟล์/QA/ยืนยันข้อมูลรายจังหวัดและปี การส่งออก การแก้ไขทีม และผลตรวจในเครื่องได้ การตั้ง URL Google เป็นตัวอย่างการตั้งค่าเท่านั้น ไม่ตรวจสิทธิ์หรืออ่าน Google จริง การมอบหมายบัญชีเป็นข้อมูลจำลอง ไม่เปลี่ยนบัญชีจริง

## เชื่อมระบบจริง
ตั้ง previewMode: false และระบุ apiEndpoint ของ Apps Script ใน site-config.js จากนั้นทำตามคู่มือ deployment เดิม ระบบจริงยังต้อง Login และตรวจสิทธิ์ที่เซิร์ฟเวอร์ โหมดไม่ต้อง Login ไม่ทำงานบน GitHub Pages และไม่ทำงานเมื่อกำหนด API endpoint แล้ว

## ผลตรวจ
ชุดทดสอบอัตโนมัติผ่าน 106/106 และ syntax JavaScript/Apps Script ผ่าน 25 ไฟล์ ตรวจหน้าเบราว์เซอร์ว่าเข้า Super Admin ได้ทันที Admin ล็อกจังหวัดและซ่อนการมอบหมายบัญชี เลือกเชียงใหม่แล้วชื่อพื้นที่/ภาพตราเปลี่ยนตรงกัน และ QA ตัวอย่างกำแพงเพชร 593 จุดทำงาน

ยังไม่ได้ deploy หรือทดสอบ Google จริง ข้อมูล HS ที่ให้มามีเฉพาะกำแพงเพชร และยังไม่มีชุดขอบเขต GIS ครบประเทศ รายละเอียดข้อจำกัดเดิมอยู่ใน NATIONAL_V2_TH.md
