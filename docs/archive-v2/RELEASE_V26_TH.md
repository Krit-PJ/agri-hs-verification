# HS Verification 2.6

## สิทธิ์พื้นที่ตามข้อสรุปของผู้ใช้
ใช้บัญชี Admin รายบุคคลและให้ Super Admin มอบหมายจังหวัด ไม่ใช้รหัสไปรษณีย์เป็นชื่อผู้ใช้/รหัสผ่านหรือเป็นขอบเขตความปลอดภัย จังหวัดเก็บเป็นรหัสอ้างอิงเบื้องหลัง ผู้สมัครเลือกชื่อจังหวัด/อำเภอ แล้ว Admin จังหวัดนั้นพิจารณาอนุมัติสังกัด เซิร์ฟเวอร์ตรวจสิทธิ์ทุกครั้ง

## สิ่งที่ปรับ
1. บันทึกโทรศัพท์ใน Google Sheets เป็นข้อความก่อนเขียน รักษาศูนย์นำหน้า และยอมรับข้อมูลเดิมที่ Sheets แปลงเป็นเลข 9 หลักเฉพาะเมื่อกู้เป็นมือถือไทยได้ บัญชีและสังกัดต้องตรงกัน หากซ้ำจะไม่ให้เข้าสู่ระบบหรือซ่อมอัตโนมัติ
2. ผู้สมัครใหม่สถานะ pending รอ Admin จังหวัดนั้นหรือ Super Admin อนุมัติ บัญชีที่อนุมัติเดิมยังใช้ได้ ไม่อนุมัติหรือปิดบัญชีเดิมทั้งชุดอัตโนมัติ
3. ตัดปุ่มจราจร เลือกเดือนภาษาไทยและปี พ.ศ. ผ่าน select ที่ใช้งานได้ข้ามอุปกรณ์
4. ย้ายตัวเลือกจังหวัดที่กำลังดูไปหน้า Admin/Super Admin ลดข้อความบัญชีซ้ำในหน้าผู้ใช้ทั่วไป
5. Super Admin สร้าง Admin รายบุคคลและมอบหมายจังหวัดได้ รหัสผ่านใหม่อย่างน้อย 10 ตัว เจ้าของบัญชีเปลี่ยนชื่อผู้ใช้หรือรหัสผ่านเองได้หลังยืนยันรหัสผ่านปัจจุบัน หากเปลี่ยนจะต้องเข้าสู่ระบบใหม่ ถ้าไม่เปลี่ยนให้ใช้บัญชีเดิมต่อไป ไม่มีการสร้างบัญชีใหม่หรือรีเซ็ตรหัสเดิมโดยอัตโนมัติ
6. เปิดชั้นขอบเขตตามบัญชีที่อนุมัติ ทั้ง Admin และผู้บันทึก ผู้บันทึกระดับอำเภอเห็นรายละเอียดอำเภอ/ตำบลเฉพาะอำเภอตน ส่วนเส้นจังหวัดเป็นบริบทของจังหวัดนั้น ชั้นอำเภอ/ตำบลปิดเริ่มต้นและโหลดเมื่อเปิดพร้อมซูมเข้า ใช้ Canvas ลดภาระ SVG
7. สำเนา HS ใน IndexedDB แยกตามฐานข้อมูล บัญชี จังหวัด อำเภอ ตำบล ระดับสังกัด และรุ่นข้อมูล ตรวจสิทธิ์/รุ่นกับเซิร์ฟเวอร์ก่อนใช้ อายุสำเนาไม่เกิน 10 นาที ปุ่มอัปเดตอ่านชุดเต็มทันที
8. สำเนาไม่เก็บ token, profile, เบอร์, หมายเหตุ, ผู้ตรวจ หรือภาพ ก่อนเปิดแก้จุดจากสำเนา ต้องอ่าน getHS ฉบับเต็มเพื่อไม่เขียนทับหมายเหตุเก่าด้วยค่าว่าง ออกจากระบบแล้วล้างสำเนา

## ติดตั้งและซ่อมข้อมูล
ใช้ docs/AppsScript-v26-All.gs แทนโค้ดรวมเดิม แล้วตรวจ checkRuntimeV26 ผลต้อง version2.6, registrationMode=approval_required
หาก phoneRepair.eligible มากกว่า 0 ให้รัน backupRegistrationBeforePhoneRepair ก่อน จากนั้น applyPhoneCellRepair และตรวจ previewPhoneCellRepair อีกครั้ง ตัวซ่อมไม่สร้างบัญชี ไม่เปลี่ยนรหัสผ่าน ไม่เปลี่ยนสิทธิ์และสถานะอนุมัติ และข้ามเลขซ้ำ/บัญชีไม่ตรง
อัปเดต deployment เดิมเป็นเวอร์ชันใหม่แล้วเผยแพร่ Frontend คู่กัน

## ข้อจำกัด
- สำเนาในเบราว์เซอร์ช่วยการเปิดซ้ำ ไม่ใช่ระบบสำรองภัยพิบัติหรือการบันทึก offline และต้องติดต่อเซิร์ฟเวอร์เพื่อตรวจสิทธิ์ก่อนใช้
- การแก้ Google Sheets ด้วยมืออาจไม่เพิ่ม revision จึงต้องกดอัปเดต หรือรออายุสำเนา 10 นาที
- การสร้าง Admin รายบุคคลต้องให้ Super Admin กรอกชื่อเจ้าของบัญชีและตั้งรหัสผ่านจริงผ่านหน้าระบบ ไม่มีการกรอกรหัสแทนบุคคลโดยผู้พัฒนา
- ขอบเขตแผนที่เป็นไฟล์สาธารณะสำหรับแสดง ไม่ใช้รับรองพิกัดหรือพื้นที่ทางกฎหมาย บางจังหวัดยังมีข้อมูลไม่ครบตามเอกสารรุ่น2.5
