# คู่มือใช้งานภาคสนาม

1. เปิด URL HTTPS ที่ผู้ดูแลแจ้ง เข้าโหมดเชื่อมต่อจริงด้วยรหัสผู้ตรวจที่ได้รับ ผู้ตรวจถูกระบุจากบัญชีที่ backend รับรอง ไม่ต้องพิมพ์ชื่อซ้ำทุกจุด
2. เลือกปี เดือน อำเภอ ตำบล หมู่บ้าน ชนิดพืช หรือสถานะ แล้วแตะจุดบนแผนที่/รายการ
3. ตรวจข้อมูล HS ที่เติมให้ ได้แก่ วันที่ เวลา ที่ตั้ง ชนิดพื้นที่/พืชและพิกัด หากไม่ตรงให้รายงานผู้ดูแล อย่าแก้ข้อมูลอ้างอิงเพื่อให้เข้ากับการสังเกต
4. กดนำทาง Google Maps เมื่อต้องเดินทาง และระวังความปลอดภัยในพื้นที่ไฟไหม้
5. เลือกผลตรวจ แนบภาพตามที่จำเป็น ใส่หมายเหตุหรือการดำเนินการเพิ่มเติมเฉพาะเมื่อมีสาระ
6. อนุญาตตำแหน่งมือถือ ตรวจค่าความแม่นยำ GPS หากไม่มี GPS ให้ระบุเหตุผลตามฟอร์ม ระยะห่างเป็นระยะเส้นตรง ไม่ใช่ระยะทางเดิน
7. ทบทวนแล้วกดยืนยัน รอข้อความสำเร็จ หากภาพบางส่วนส่งไม่สำเร็จทำตามข้อความ retry อย่าตีความว่ารูปครบเพียงเพราะผลตรวจถูกบันทึก
8. เมื่อสัญญาณอ่อน ไม่ปิดหน้าก่อนทราบผล การบันทึกซ้ำด้วย request ID เดิมช่วยป้องกันรายงานซ้ำ แต่ต้องตรวจสถานะ server หลังเชื่อมต่ออีกครั้ง
9. ออกจากระบบหลังใช้เครื่องร่วมกัน ไม่ส่ง token ลงกลุ่มแชทและไม่เผยแพร่ภาพที่มีข้อมูลบุคคลโดยไม่จำเป็น

โหมดทดลองแสดงไว้อย่างชัดเจน ใช้เพื่อฝึกเท่านั้น แผนที่พื้นหลังและรูปภาพออนไลน์ต้องใช้อินเทอร์เน็ต ระบบ v1 ไม่ใช่แอป offline sync เต็มรูปแบบ
