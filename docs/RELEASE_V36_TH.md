# รุ่น 3.6 — ประเภทพื้นที่ (เลือกได้หลายประเภท) · ช่วงเดือน · จุด HS จาก API ระบบ Agri-Risk Map

ต้องอัปเดต Apps Script (ping = 3.6.0)

## แหล่งข้อมูล (คงตามระบบเดิม)
* จุดความร้อนมาจาก **API ระบบ Agri-Risk Map Burning** (`action=api&fn=hotspots`) — แหล่งเดียวกับเว็บ Risk Map: ข้อมูล AGENCY, คอลัมน์ประเภทพื้นที่ (landType) และนโยบายดาวเทียม (NOAA-20 ตั้งแต่วันแรกที่มีข้อมูล ก่อนหน้านั้น Suomi-NPP)
  ตรวจเทียบไฟล์ `HS_NOAA-20_2.xlsx` (NOAA20_2026 → LandType) จังหวัดกำแพงเพชร 1 ม.ค.–13 พ.ย. 2569 ตรงกันทุกประเภท: พื้นที่เกษตร 489 · เขต สปก. 479 · ป่าอนุรักษ์ 2,059 · ป่าสงวนแห่งชาติ 510 · ชุมชนและอื่น ๆ 76 · พื้นที่ริมทางหลวง 8
* `apiEndpoint` (Apps Script ของระบบนี้) ยังใช้สำหรับเข้าสู่ระบบ บันทึกผลตรวจ ภาพ และสถานะผลตรวจ (คำสั่งใหม่ `hs_status`) — ไม่ได้แทนด้วย API ของ Risk Map เพราะ API นั้นไม่มีส่วนบัญชีและบันทึกผล
* ตั้งค่าใน `site-config.js` → `riskMapApi`

## ประเภทพื้นที่
* แยก 6 ประเภทเหมือนไฟล์: พื้นที่เกษตร · เขต สปก. · ป่าสงวนแห่งชาติ · ป่าอนุรักษ์ · ชุมชนและอื่น ๆ · พื้นที่ริมทางหลวง
* ค่าเริ่มต้น **พื้นที่เกษตร** เท่านั้น · เลือกได้ 1 ประเภทหรือมากกว่า (ช่องทำเครื่องหมาย + ตกลง) · ปุ่ม "เลือกทุกประเภท" และ "ค่าเริ่มต้น"
* API รับครั้งละ 1 ประเภท ระบบจึงขอแยกประเภทแบบขนานแล้วรวมผล (การขอ "ทุกประเภท" ครั้งเดียวใช้เวลาราว 20 วินาที) · จำค่าในหน้าเว็บ 5 นาที สลับกลับไปมาได้ทันที
* เลือกมากกว่า 1 ประเภท การ์ดแต่ละจุดแสดงประเภทพื้นที่

## ช่วงเวลา
* เลือก **ตั้งแต่ เดือน ปี — ถึง เดือน ปี** (จัดกลุ่มตาม พ.ศ.) แทนตัวเลือกปีงบประมาณ
* ค่าเริ่มต้น **ม.ค. 2569 ถึงเดือนของข้อมูลล่าสุด** ของจังหวัด (ทุกจังหวัด = เดือนล่าสุดของทุกจังหวัด)
* "ล้างตัวกรองทั้งหมด" คืนประเภทพื้นที่และช่วงเวลาเป็นค่าเริ่มต้นด้วย
* หน้าสรุปผล / รายงานพิมพ์ระบุประเภทพื้นที่และช่วงเดือน

## หน้าจอ
* คอมพิวเตอร์: จังหวัด · ประเภทพื้นที่ · ตั้งแต่ · ถึง · ตัวกรอง · ↻ อยู่แถวเดียว
* มือถือ: จังหวัด / ประเภทพื้นที่ + ตัวกรอง + ↻ / ตั้งแต่ + ถึง · รายการประเภทพื้นที่เปิดเป็นแผ่นด้านล่างจอ ปุ่มแตะสูง 44 px · ทดสอบ 390 และ 360 px ไม่ล้นจอ
