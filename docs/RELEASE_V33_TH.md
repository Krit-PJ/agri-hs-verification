## สิ่งที่ปรับ

* **แถบเครื่องมือเดียว** ใต้เมนู: จังหวัด · ช่วงเวลา (เลือกตามปีงบประมาณ / ทุกช่วง / กำหนดเอง) · ปุ่ม **ตัวกรอง** (แสดงจำนวนตัวกรองที่ใช้) · ปุ่มรีเฟรช — ติดอยู่ด้านบนเมื่อเลื่อน
* ตัวกรองละเอียดซ่อนในลิ้นชัก เมื่อใช้แล้วแสดงเป็น **ชิป** กด × เพื่อล้างทีละตัว หรือ “ล้างทั้งหมด”
* **แผนที่อยู่ในจอแรก** และสูงเต็มพื้นที่ที่เหลือ รายการจุดอยู่ข้างแผนที่ เลื่อนในกรอบของตัวเอง
* แถบผลลัพธ์บรรทัดเดียว: จำนวนจุด + ป้ายสถานะ (ตรวจแล้ว / รอตรวจ / พบการเผา)
* การ์ดจุด HS: พื้นที่ + สถานะ, พืช · วันที่, ปุ่มเดียว **บันทึกผล ›** หรือ **ดู / แก้ไข ›** — ผู้ใช้ทั่วไปไม่เห็นปุ่มบันทึก
* ปุ่ม **จุดรอตรวจใกล้ฉัน** แสดงเฉพาะเจ้าหน้าที่ที่บันทึกได้
* เมนูหลักเหลือ 3–4 รายการ (ตรวจสอบ · สรุปผล · ผู้ดูแล/งานของฉัน · เข้า/ออกระบบ) ลิงก์ระบบอื่นย้ายไปส่วนท้าย
* ชิปชื่อผู้ใช้ที่หัวเว็บ (ไม่แสดงข้อความซ้ำ) และไม่มีปุ่มออกจากระบบซ้ำในหน้าผู้ดูแล
* **ผู้ดูแลเหลือ 4 แท็บ**: บัญชีผู้ใช้ (รวมผู้ลงทะเบียนใหม่ + ตัวกรอง ทั้งหมด/ใหม่ 7 วัน/Mini Super Admin/ระงับ + ค้นหา + ปุ่มเพิ่ม) · ผลการตรวจสอบ · ประวัติการใช้งาน (สลับ “การเข้าใช้งานระบบ” / “การบันทึก-แก้ไขข้อมูล”) · ตั้งค่า
* ฟอร์มค้นหาประวัติแบบบรรทัดเดียว ตัวกรองเพิ่มเติมพับไว้ใน “ตัวกรองเพิ่มเติม”
