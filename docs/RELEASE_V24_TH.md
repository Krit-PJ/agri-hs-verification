# HS Verification 2.4

ปรับการลงทะเบียนเป็นสร้างบัญชีผู้บันทึกและเข้าสู่ระบบด้วยหมายเลขโทรศัพท์ได้ทันที ไม่ต้องสมัครซ้ำ โดยยังจำกัดข้อมูลตามจังหวัด/อำเภอของบัญชี ผู้ดูแลยังใช้ชื่อผู้ใช้และรหัสผ่านเดิม ผู้ดูแลสามารถระงับบัญชีได้ การใช้เบอร์อย่างเดียวไม่พิสูจน์ความเป็นเจ้าของเบอร์

## สิ่งที่ปรับ
- หลังสมัครเปิดหน้าเข้าสู่ระบบ พร้อมจำหมายเลขล่าสุดในอุปกรณ์ตามตัวเลือก
- แสดงชื่อและสังกัดของผู้ที่เข้าใช้งาน หน้าต่างปรับตามมือถือ แท็บเล็ต และคอมพิวเตอร์
- เลือกช่วงเดือน–ปี เริ่มตุลาคมของปีงบประมาณข้อมูลล่าสุด ถึงเดือนล่าสุดที่มีข้อมูล และเลือกจังหวัดในค้นหาเร็ว
- แผนที่เลือกถนน ดาวเทียม ภูมิประเทศ สีจุดอิงผลตรวจที่บันทึกแล้ว งานร่างใช้สีแยก
- จราจรเปิดใน Google Maps (ลิงก์ภายนอก ไม่ใช่ชั้นจราจรที่ฝังในเว็บ)
- เก็บยอดเข้าชมและจำนวนผู้ใช้รายวันโดยประมาณใน Script Properties ไม่เก็บเบอร์หรือ IP ในสถิติ ไม่ใช่จำนวนบุคคลไม่ซ้ำที่รับรองได้
- รายงานโหลดภาพที่บัญชีมีสิทธิ์อ่านก่อนพิมพ์ เก็บสำเนารายงานใน IndexedDB อายุ 1 ชั่วโมง แยกเหตุผลไม่มีภาพจากข้อผิดพลาดการโหลด
- เพิ่มผลตรวจเข้าตรวจสอบไม่ได้ และนับในรายการติดตาม

## ติดตั้ง
ใช้ docs/AppsScript-v24-All.gs แทนโค้ดรวมเดิมในโครงการ Apps Script แล้วบันทึกและอัปเดต deployment เดิมเป็นเวอร์ชันใหม่ ไม่ต้องสร้าง Spreadsheet หรือรีเซ็ตรหัสผู้ดูแล

ตรวจ getRegistrationPolicy ว่า configured=true, authMethod=phone_only และ registrationMode=immediate ก่อนเปิดรับสมัคร Frontend รุ่นนี้จะไม่เปิดรับสมัครกับ API รุ่นเก่าที่ยังรออนุมัติ

บัญชีเก่าที่ค้างรออนุมัติยังต้องให้ผู้ดูแลตรวจรายการเดิม การปรับนี้ไม่อนุมัติบัญชีเก่าทั้งหมดอัตโนมัติ

## ตรวจสอบ
ผ่านการทดสอบอัตโนมัติ 154 รายการ ครอบคลุมบัญชี สิทธิ์ ช่วงเวลา สีสถานะ รูปภาพ รายงาน และสถิติ ไม่สร้างบัญชีทดสอบลงฐานข้อมูลจริง
