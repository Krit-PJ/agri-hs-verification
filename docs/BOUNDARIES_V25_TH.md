# ขอบเขตการปกครอง — Frontend 2.5

นำเข้าจากชุดที่ผู้ใช้กำหนด `พร้อมนำเข้า_F4/ชุดนำเข้า/แผนที่รายจังหวัด` โดยใช้ทะเบียนรหัสใน `config/provinces.import-ready.json` ไม่แก้ต้นฉบับ

## ใช้งาน

1. เข้าสู่ระบบ Admin หรือ Super Admin แล้วเปิดตรวจสอบจุดความร้อน
2. เลือกเปิด/ปิด จังหวัด อำเภอ ตำบล จากแผงขอบเขตเหนือแผนที่
3. Admin เห็นเฉพาะจังหวัดที่เซิร์ฟเวอร์มอบหมาย เปลี่ยนจังหวัดในแผงนี้ไม่ได้
4. Super Admin เลือกทั่วประเทศหรือหนึ่งจังหวัด แล้วกดดูเต็มขอบเขตได้ การเลือกนี้เปลี่ยนขอบเขตแผนที่ ไม่เปลี่ยนตัวกรอง HS
5. อำเภอแสดงตั้งแต่ zoom 8 ตำบลตั้งแต่ zoom 10 โหลดเฉพาะจังหวัดในจอ จำกัดอำเภอไม่เกิน 8 จังหวัด/ตำบลไม่เกิน 4 จังหวัดพร้อมกัน หากมุมมองกว้างกว่านี้ให้ซูมเข้า

จังหวัดสีเขียว อำเภอสีน้ำตาล ตำบลเส้นประสีม่วง จุด HS ยังอยู่เหนือเส้นขอบเขต กดปิดชั้นที่ไม่ต้องการได้ ชื่อพื้นที่และรหัสแสดงเมื่อชี้เส้นบนคอมพิวเตอร์

## ข้อมูลและข้อจำกัด

- ชุดนี้มี 77 จังหวัด 929 อำเภอ 7,331 ตำบล (จำนวนตามไฟล์ ไม่ใช่การรับรองจำนวนเขตปกครองปัจจุบัน)
- รายงานต้นทางระบุ 35 จังหวัดมี core coverage บางส่วน และกันรหัสที่ยังไม่ยืนยัน 206 รหัสออก จึงไม่สร้างพื้นที่ที่ขาดเพิ่มเอง
- พิกัด WGS84 longitude/latitude ตรวจ geometry แสดงผล 8,337 รายการ ไม่พบ geometry ว่าง/ผิดรูปหรือพิกัดหลุดช่วงตรวจ
- ลดรายละเอียดด้วย Shapely preserve_topology ต่อ feature: จังหวัด .0003 องศา อำเภอ .00015 ตำบล .00008 พร้อมเก็บรหัส ชื่อ และจังหวัดแม่
- ไฟล์แสดงผลรายจังหวัดรวมประมาณ 38.1 MB จากต้นทางประมาณ 524.7 MB; overview จังหวัดประมาณ 2.5 MB โหลดรายละเอียดตามจอและใช้ cache จำกัด
- การลดรายละเอียดแต่ละ feature อาจทำให้ขอบร่วมคลาดกันเล็กน้อยเมื่อซูมสูง ไม่ใช้เป็นแนวเขตรังวัด คำนวณพื้นที่ หรือยืนยันว่าพิกัด HS อยู่จังหวัดใด
- การเพิ่มนี้ไม่ทำให้ QA นำเข้า HS ผ่าน spatial validation อัตโนมัติ และไม่เปลี่ยนค่ารับรอง boundaryVerified
- ไม่รวมจุดหมู่บ้าน เพราะงานนี้ขอขอบเขตจังหวัด อำเภอ และตำบล

## สิทธิ์และการเผยแพร่

ไฟล์ GeoJSON บน GitHub Pages เป็นข้อมูลแผนที่สาธารณะ การจำกัดตามสิทธิ์เป็นการเลือกแสดงในแอป ไม่ใช่การซ่อนไฟล์ GeoJSON จากผู้ที่รู้ URL การอ่าน/บันทึก HS และภาพส่วนบุคคลยังตรวจสิทธิ์บน Apps Script ตามเดิม ไม่ใช้ค่าจากแผงขอบเขตเป็นสิทธิ์เซิร์ฟเวอร์

ไม่ต้องเปลี่ยน Google Sheets หรือ deployment Apps Script รุ่น 2.4 ในงานนี้

## ไฟล์สำคัญ

- `boundaries.js`, `boundaries.css`: แผงควบคุมและตัวโหลด Leaflet
- `data/boundaries/index.json`: ทะเบียนไฟล์ ขอบเขต bbox และข้อจำกัดรายจังหวัด
- `data/boundaries/build-qa.json`: SHA256 ต้นทาง จำนวน feature ขนาดและ tolerance
- `scripts/build-boundaries.py`: สร้างไฟล์แสดงผลซ้ำ (ต้องติดตั้ง Shapely ใน `.boundary-tools` หรือ Python environment)
- `docs/boundary-preview.html`: ตัวอย่างทดสอบสิทธิ์จำลองเฉพาะ localhost ไม่เชื่อมข้อมูลจริง
- `tests/boundaries.test.js`: ตรวจสิทธิ์ แผนการโหลด ชุดข้อมูล และการออกจากระบบระหว่างโหลด

ตัวอย่างคำสั่งสร้างไฟล์จาก root ของ repository:

```powershell
python -m pip install --target .boundary-tools shapely
python scripts/build-boundaries.py 'C:\Users\Krit\Desktop\1. ขอบเขตพื้นที่รายจังหวัด\พร้อมนำเข้า_F4\ชุดนำเข้า'
npm test
```
