# รุ่น 2.2.2 — ค่านโยบายที่ผู้ดูแลระบุ

ช่องทางติดต่อ PDPA: kamphaengphet.doae@gmail.com
ระยะเก็บรักษา: ตามนโยบายและข้อกำหนดของหน่วยงาน สำนักงานเกษตรจังหวัดกำแพงเพชร
ผู้ควบคุมข้อมูล: สำนักงานเกษตรจังหวัดกำแพงเพชร / กรมส่งเสริมการเกษตร

นำลิงก์ “อ่านประกาศความเป็นส่วนตัวฉบับเต็ม (เปิดหน้าใหม่)” ออกจาก registration-ui.js และ docs/consent-preview.html โดยคงรายละเอียดการใช้ข้อมูลและสิทธิไว้ในหน้าลงทะเบียน

Apps Script: ใช้โค้ดแบบแยก apps-script/ หรือไฟล์รวม docs/AppsScript-v22-All.gs อย่างใดอย่างหนึ่ง จากนั้นเรียก setupApprovedPrivacyPolicy หนึ่งครั้ง ฟังก์ชันเปลี่ยนเฉพาะ PRIVACY_CONTROLLER, PRIVACY_CONTACT และ PRIVACY_RETENTION ไม่แก้ข้อมูล HS หรือบัญชีผู้ใช้ แล้วตรวจ checkRegistrationPolicyReady ให้ configured=true

ค่าระยะเก็บรักษาที่ระบุเป็นข้อความอ้างอิงนโยบาย ไม่ได้กำหนดจำนวนปี ไม่ใช่คำสั่งลบอัตโนมัติ และไม่ใช่การรับรองว่าเก็บได้ไม่จำกัด หน่วยงานควรมีนโยบายกำหนดระยะหรือเกณฑ์สิ้นสุดและขั้นตอนลบไว้ให้ตรวจสอบได้

ระบบยังใช้การอนุมัติผู้สมัครโดยผู้ดูแล ไม่มี OTP และมีเพดานบัญชีเริ่มต้น200รายตามข้อจำกัดเดิม เหมาะสำหรับระยะนำร่อง ยังไม่ใช่ระบบบัญชีระดับประเทศปริมาณสูง

สถานะจริง: เผยแพร่ Apps Script deployment เวอร์ชัน4 วันที่18ตุลาคม2569 เวลา07:06 ใช้ URL และสิทธิ์เดิม API ตอบ configured=true และตรวจค่า contact/retention ตรงตามที่ระบุ ชุดทดสอบ126รายการผ่าน Frontend ใหม่ยังอยู่ในตัวอย่างท้องถิ่นและชุดโค้ด ยังไม่เผยแพร่ขึ้น GitHub Pages
