# รุ่น 3.5 — ลงทะเบียนไม่หมดเวลา · การ์ดจุดไม่ซ้อนกัน · ลิงก์ด้านบน · มือถือ

ต้องอัปเดต Apps Script (ping = 3.5.0)

## 1. "Time out" ตอนลงทะเบียน Admin
**สาเหตุ**: ทุกคำสั่งบันทึกใช้ "คิวล็อก" เดียวกันของ Apps Script และมีงานที่ยึดคิวนาน
* ตัวนับผู้เข้าชม (ทำงานทุกครั้งที่มีคนเปิดเว็บ) ล็อกคิว และระหว่างนั้นอ่านชีต AuditLog ทั้งชีตเพื่อนับเจ้าหน้าที่ใช้งานวันนี้ — ค่าที่จำไว้ถูกล้างทุกครั้งที่เจ้าหน้าที่ทำรายการ จึงอ่านใหม่เกือบทุกครั้ง
* การแนบภาพเขียนไฟล์ลง Drive ระหว่างที่ยึดคิว
ช่วงคนใช้มาก การลงทะเบียนรอคิวเกิน 20 วินาที → Apps Script แจ้ง `Lock timeout`

**แก้ไข (Apps Script)**
* ตัวนับผู้เข้าชมไม่แย่งคิว: อ่านไม่ล็อก นับเพิ่มเฉพาะเมื่อได้คิวภายใน 1.5 วินาที · นับเจ้าหน้าที่วันนี้นอกคิว อ่านเฉพาะ 4,000 แถวท้าย AuditLog และจำค่าไว้ 5 นาที
* ลงทะเบียน: ล็อกเฉพาะช่วงตรวจเบอร์ซ้ำ + เพิ่มบัญชี บันทึกประกอบ (คำขอ/ประวัติ) ทำนอกคิว
* แนบภาพ: เขียนไฟล์ Drive นอกคิว ล็อกเฉพาะตอนเพิ่มแถว ถ้าบันทึกไม่สำเร็จลบไฟล์ทิ้ง ไม่มีไฟล์ค้าง
* ถ้ายังรอคิวไม่ได้ (28 วินาที) แจ้งเป็นภาษาไทยว่ายังไม่ได้บันทึก ให้กดลองใหม่ — ไม่ใช่ `Lock timeout`

**แก้ไข (หน้าเว็บ)**
* รอได้ 60 วินาที และแสดงสถานะระหว่างรอ
* ถ้าสัญญาณหลุด/ตอบช้า ระบบตรวจว่าบันทึกไปแล้วหรือยังและเข้าสู่ระบบให้อัตโนมัติ (ลองสูงสุด 3 ครั้ง) · ถ้าเบอร์ลงทะเบียนไว้แล้วจะเข้าสู่ระบบให้ทันที ไม่ต้องกรอกซ้ำ
* หัวหน้าต่างเปลี่ยนเป็น "ลงทะเบียน Admin"

## 2. การ์ดจุด HS ซ้อนทับกัน
**สาเหตุ**: รายการด้านขวาเป็นกล่องความสูงจำกัด การ์ดถูกบีบเหลือ ~26 px เมื่อมีจุดจำนวนมาก (ทดสอบรุ่นก่อนมีเพียง 2 จุดจึงไม่พบ)
**แก้ไข**: การ์ดคงความสูงตามเนื้อหา และจัดโครงใหม่ — หมู่บ้าน + สถานะ / ตำบล · อำเภอ / พืช · วันเวลา · ภาพ · ระยะ / รหัส HS · แผนที่ · ปุ่มบันทึก พร้อมแถบสีซ้ายตามสถานะ · ทดสอบกับ 300 จุด ที่ 1366, 1280, 1024, 390, 360 px ไม่ซ้อนและไม่ถูกตัด

## 3. ลิงก์ที่เกี่ยวข้อง
ย้ายขึ้นเมนูด้านบน เป็นปุ่ม **ลิงก์ที่เกี่ยวข้อง ▾** ถัดจาก "งานของฉัน/ผู้ดูแลระบบ" (Agri-Risk Map Burning · Green Gain Hub · ทีมผู้พัฒนาและที่ปรึกษา · ความเป็นส่วนตัว) ปิดด้วย Esc หรือคลิกที่อื่น · บนมือถืออยู่ในเมนู ☰ เป็นหมวดแยก · ท้ายหน้าคงลิงก์นโยบายความเป็นส่วนตัวไว้ตามมาตรฐานเว็บไซต์

## 4. มือถือ
* หัวเว็บสูงจาก 78 → 60 px ชื่อระบบบรรทัดเดียว คำบรรยายสั้น "จังหวัดกำแพงเพชร"
* แถบผลลัพธ์ (จำนวนจุด + สลับแผนที่/รายการ) อยู่บรรทัดเดียว ติดใต้หัวเว็บเมื่อเลื่อน
* รายการจุดเลื่อนพร้อมหน้าเว็บ (ไม่มีกรอบเลื่อนซ้อน) การ์ดเต็มความกว้าง ปุ่มแตะสูง ≥ 40 px
* แผนที่สูง 58% ของจอ · ช่วงเวลาแสดงแบบสั้น "ปีงบ 2569" บนจอแคบ · แท็บในหน้าต่างเข้าใช้งานไม่ตัดบรรทัด
